Веб-приложение (сайт)
Отображается список сгенерированных пользователем товаров
Пользователь может добавить новый товар:
Пользователь загружает фото товара для создания генерации
Система автоматически определяет категорию товара (например “одежда и обувь”) 
В приложении доступны следующие категории товара:
Одежда и обувь
Аксессуары
Еда и напитки
Косметика и уход
Гаджеты и техника
Дом и мебель
Прочее
Система автоматически определяет товар (например “куртка”) 



Пользователь выбирает тип генерации (доступно только “фото” или “карточка” (генерируется карусель фото + заголовок + описание)) 
Пользователь выбирает “Как показать товар”
Отображаются предсозданные варианты (по 4 штуки на любую категорию товара, кроме категории “прочее”) 
Пользователь может добавить пожелания / описание в поле свободного ввода
Пользователь выбирает, сколько объектов ему сгенерировать
от количества объектов зависит цена генерации
Пользователь может запустить генерацию
Запустить генерацию может только зарегистрированный пользователь 
Если пользователь не зарегистрирован, то предлагаем зарегистрироваться (см. “Регистрация / Авторизация”) 
Пользователь видит результат генерации
Пользователь может скачать получившиеся изображения на свой компьютер

Данная генерация добавляется в каталог генераций пользователя, с названием данным ИИ
Пользователь в любой момент может перейти в эту генерацию повторно, чтобы загрузить материалы	



Регистрация/Авторизация:
Пользователь может авторизоваться в приложении с помощью email + пароль
Есть функционал забыли пароль
Если пользователь не зарегистрирован, то предлагаем зарегистрироваться
Пользователь указывает email
Указывает пароль
Подтверждает пароль
После регистрации пользователь получает N баллов на свой баланс

Профиль:
Отображается баланс пользователя в баллах
Пользователь может пополнить баланс, выбрав подходящий пакет (как в играх) 
Эквайринг не подключаем. После выбора пакета баллы автоматически зачисляются на счет
Пользователь может выйти из аккаунта
